GitHub link (one-time setup)

Claude's scheduled task can only read your GitHub repo, so Save sends these settings there through your gallery Worker. It needs a GitHub token saved in the Worker once:
  1. GitHub, your profile picture, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Name it "FOM Worker channel", set an expiry (1 year), Resource owner FOMStudios, Repository access Only select repositories: dashboard.
  3. Permissions, Repository permissions, Contents: Read and write. Nothing else. Generate, then copy the token.
  4. If GitHub says the organisation must approve it: Organisation FOMStudios, Settings, Personal access tokens, Pending requests, Approve.
  5. Cloudflare, Workers and Pages, fom-gallery, Settings, Variables and Secrets, Add, type Secret, name GH_TOKEN, paste, Deploy.
Then press Save on this page: the badge at the top turns green ("Claude has your settings").
